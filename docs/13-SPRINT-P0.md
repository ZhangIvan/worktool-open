# P0 冲刺方案（Sprint Plan）v1.0

- 版本：v1.0（2026-11-03；用户指令：立即启动，最佳建议推进，不再零碎）
- **目标 GOAL：24h 内交付一个你自己能安装、能配对、能看到企微被自动操作的 APK + 05 矩阵至少 5 格翻 ✅**

## 一、三车道并行

| 车道 | 交付 | DoD |
|------|------|-----|
| **A·产品 App** | 用户面完整：主屏（状态卡：在线/离线/server 地址/暂停按钮）+ 配对流（输入地址→扫码/输码→完成）+ 关于页 | 用户能独立完成 安装→配对→看状态 全流程 |
| **B·真机 P0** | 8 执行器在 D1 上真实驱动企微 UI（非 FakeNode）→截图/日志/RAW_CONFIRM 三源取证→05 矩阵翻格 | ≥5 条指令 ✅（≥5 次成功） |
| **C·APK 打包** | 签名 Release APK + 版本号 + Release Notes 草稿 | 用户可 adb install 或直接安装 |

## 二、执行顺序

```
Phase 1: 三车道并行（A/B/C 同时开工）
Phase 2: CR 门（A 车道产出评审）
Phase 3: 真机集成验收（A 的 APK + B 的执行 → 合并跑一轮端到端）
Phase 4: 打包推送 + 交付报告
```
