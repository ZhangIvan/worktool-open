# 需求规格 v2（WorkTool-Open）

- 版本：v2.2（2026-11-02，用户审阅意见落地）；权威功能依据：`local-private/audit/02-reference-repo-analysis.md` D 表（F1~F44）、`local-private/audit/01-apk-static-analysis.md`（delta 新增能力）、apifox 对外接口文档（doc-850007，REST 面）
- 优先级定义：P0=v0.1 必须 / P1=v0.2 / P2=v1.0 / P3= backlog
- 落位：端=Android 端侧；服=自建服务端；双=两侧都要
- 通用验收模板：凡备注含"指令 N"的 FR，验收统一为"真机 D1 连续 ≥5 次执行成功且执行结果回执错误码=0（RAW_CONFIRM+错误码体系 0/10xxx/20xxx/50xxx）"；查询类为"返回结构通过 `protocol/` JSON Schema 校验"

## 2. 非功能需求（NFR）

### 2.1 安全（SR，源自 audit/01 P0/P1 与 audit/02 §E）
| ID | 要求 | 验证方式 |
|----|------|----------|
| SR-01 | 禁用 trust-all TrustManager/HostnameVerifier，默认系统校验 | 代码门禁 grep + 单测 |
| SR-02 | 移除硬编码 AES key（9876543210abcdef），加密可关、key 可配/握手下发 | grep 门禁 + 配置测试 |
| SR-03 | 默认零遥测：移除 Umeng/TalkingData/crashsdk 外发，崩溃日志仅本地 | APK 内无 umeng/talkingdata/ucweb 特征（grep 门禁） |
| SR-04 | 出网白名单：networkSecurityConfig + 运行时 OkHttp 拦截器双保险，默认仅用户配置服务端域名 | 静态检查 + 抓包验证（动态 runbook 用例） |
| SR-05 | 敏感存储加密（Keystore/EncryptedSharedPreferences），无明文账号/robotId/token | 设备数据检查用例 |
| SR-06 | 日志脱敏：消息正文/手机号/token 默认不落日志 | 单测 + logcat 用例 |
| SR-07 | 自更新仅 HTTPS + APK v2/v3 签名校验 + 默认关闭 | 集成测试 |
| SR-08 | 服务端鉴权：robotId+配对 token，指令含 HMAC 防篡改，全链路 TLS | 协议单测 + 渗透自查 |
| SR-09 | 移除明文 WS 与裸 IP 回退；明文仅限用户显式开启的内网场景 | 配置矩阵测试 |
| SR-10 | 组件最小化：无伪装服务名、exported 最小、allowBackup=false、无 QUERY_ALL_PACKAGES 滥用 | manifest 审查项 |
| SR-11 | 指令参数安全：fileUrl/fileBase64 等外链资源仅允许用户白名单域（默认拒收） | 协议单测+服务端校验用例（对齐 audit/02 E19） |

### 2.2 兼容与性能
- Android ≥8.0（minSdk 26，与既有实现一致；如需更低设备再评估降至 24）；企微兼容范围 **4.1.8~4.1.39 与 5.0.0~5.0.10**（用户确认 2026-11-02），开发/验证默认基线 5.0.x 最新稳定；逐指令支持矩阵见 `docs/05-SUPPORT-MATRIX.md`。
- 指令端到端延迟（内网）≤2s；心跳 5s；断线重连指数退避 ≤60s 上限。
- 服务端单机（2C4G）支撑 ≥50 机器人在线、60QPM API（对齐 apifox 限制值）。

### 2.3 可维护与共建
- 协议文档（`protocol/`）公开且为单测夹具来源（文档=测试数据，防漂移）。
- 端侧控件定位规则外置为配置（降低企微改版适配成本，R1 缓解）。
- 中英双语 README；issue/PR 模板齐全。

## 3. 明确不做（Out of Scope）
- 不破解/绕过任何商业授权；不复刻厂商闭源后台的增值付费功能（多租户计费等）。
- 不内置任何统计/广告 SDK；不做云托管 SaaS。
- 个人微信自动化**已纳入范围**（FR-56，2026-11-03 用户确认双端；厂商原文本就支持双端）：默认关闭、用户显式开启，风控风险自担（R7）。
- 不做环境对抗类功能：Root/Hook/实名检测（F39）、防卡顿模式（F41）、浏览器控制台（F43）。
- 不做捐赠/日志分享（F44 部分）、官方 Demo 机器人（F21）、自动降亮度（闭源版 delta）。
