# 设备作业安全规程（Device Safety Protocol）v1.0

- 版本：v1.0（2026-11-03；起因：W-M4 真机驾驶员无规程约束盲跑 36 分钟、应用↔企微反复跳转，所有者叫停——**任何真机会话必须先过本规程**）
- 适用：一切经 RIG/adb 触碰 D1（及未来任何测试设备）的自动化作业

## 0. 铁律（违反=立即终止会话）
1. **账号保全高于一切取证**：可疑即停，宁可丢证据不可冒险。
2. **两次失败=终局停止**：任一 UI 流程连续失败 2 次（含"找不到节点/跳转没发生/回退异常"）→ 立即停止该流程、保留现场、如实上报，**禁止第三次的盲目重试或换姿势硬闯**（本次事故的直接根因）。
3. **会话总时长上限 20 分钟**（连续企微前台操作 ≤10 分钟）；超时强制收尾撤离。
4. **动作节奏拟人**：相邻 UI 动作间隔 ≥800ms 随机抖动；单会话 UI 动作总数 ≤300。
5. **禁区**：登录/退出/切换账号、任何真实联系人/真实群的写操作、通讯录导入、支付/收款确认（235 金额类一律 dry-run）、企微设置页除只读导航外的一切修改（FR-58 关通知类功能在测试小号到位前 NOT_RUN）。

## 1. 会话前检查单（每会话必做，结果入证据）
- [ ] 确认目标包名与预期一致（防串规则包：FR-56 交叉 fail-closed）
- [ ] 截取基线屏幕+前台包名；记录会话开始时间
- [ ] 确认本次会话的**每一步计划已写成清单**（步骤/期望/失败处置）——无清单不作业
- [ ] 检测风控信号预检：当前屏幕若已有"异常/验证/操作频繁"类弹窗 → 取消会话并上报

## 2. 风控信号 → 立即全停
任何时刻屏幕出现：验证码/滑块/人脸、"操作频繁/账号异常/风险提示"、非预期的账号选择页、登录页 → **立即终止整个会话**（不是跳过重试）：force-stop 我方应用 → 禁用无障碍 → 截图存证 → 上报所有者。检测手段：每 5 次 UI 动作做一次屏幕文本扫描（RIG dump 或 OCR 白名单词表）。

## 3. 撤离例程（会话正常/异常结束都执行）
force-stop 我方应用 → 从 `enabled_accessibility_services` 移除我方服务 → 回到桌面 → 终态截图归档 `local-private/evidence/<date>/session-exit.png`。
**急停通道**（所有者可随时人工执行）：RIG `d.application('cn.worktool.open.lab').stop()`。

## 4. 授权门（所有者确认制）
- 当前真实账号上的会话：**每次会话前需所有者点头**（一条消息即可），且仅限 dry-run/只读。
- 测试小号到位后：小号会话免逐次确认（仍受铁律 1~5 约束），真实账号会话继续逐次确认。
- 任何新指令类型的**首次真机执行**（即使 dry-run）需单独声明并获准。

## 5. 与既有制度的衔接
- 工作流内"设备取证小队"驾驶员 persona 必须内嵌本规程全文要点+会话计划模板；观察员/整理员不受限（不碰设备）。
- AUD 台账记会话：起止时间/动作计数/失败与停机原因/撤离确认——04 §9 分层"L-真实设备"层证据必须含本规程检查单完成记录。
- 本规程违反产出的任何证据**作废**（不计入矩阵翻转依据）。
