1. **指令行为 1:1**：语义、触发、参数面、结果回执对齐厂商（v1 数字信封通道保持兼容，ADR-03/08）；

4. **双端维度（FR-56，2026-11-03 用户确认）**：证据口径更正（2026-11-03 双源深审）——APK 3.9.1.5 无 com.tencent.mm 自动化路径（M0 复查实证，manifest queries 仅企微族，"微信"字样均为企微侧 interop）；双端宣称仅见于 apifox 文档面且有 CMD-243 个微扫码入群佐证 → **WeChat 规则包为自研、无厂商参照，风险自担（R7）**。B2/W-M5 起每批交付 **WeCom/WeChat 双规则包**（同执行器引擎，规则按应用分形，交叉误配 fail-closed）；05 矩阵增 App 维度两列；企微专属指令（221/222/223/208/209/210）微信侧 N/A；微信默认关闭+风险确认（R7）。
